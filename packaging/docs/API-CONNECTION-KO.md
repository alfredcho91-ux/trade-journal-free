# API 연결 방법

Trade Journal은 거래소에서 거래 기록을 읽어와 매매일지와 분석을 만드는 프로그램입니다. 주문, 포지션 변경, 출금은 실행하지 않습니다.

## 1. 거래소에서 API 키 만들기

1. 사용할 거래소에 로그인합니다.
2. API 관리 화면에서 새 API 키를 만듭니다.
3. 권한은 반드시 **읽기 전용(Read Only)** 으로 설정합니다.
4. 주문, 선물 주문, 출금, 자산 이동 권한은 모두 끕니다.
5. 가능하면 사용 중인 컴퓨터의 IP만 허용하는 IP 제한을 설정합니다.
6. API Key와 Secret을 한 번만 표시하는 거래소라면 안전한 곳에 임시로 보관합니다.

지원 거래소는 Deepcoin, Binance, Bybit, OKX입니다. 거래소에 따라 API Secret 외에 Passphrase가 필요할 수 있습니다.

## 2. Trade Journal에 연결하기

1. Trade Journal을 실행합니다.
2. `매매일지` 화면에서 `API 연결`을 엽니다.
3. 거래소를 선택합니다.
4. API Key와 API Secret을 입력합니다.
5. OKX 또는 Deepcoin처럼 필요한 거래소는 Passphrase도 입력합니다. Passphrase는 거래소 API를 만들 때 직접 정한 별도 비밀번호입니다.
6. `연결 확인 및 저장`을 누릅니다.
7. 처음 연결하면 기본 최근 30일 거래가 한 번 자동 동기화됩니다.

연결 후에는 `동기화` 버튼으로 원하는 기간의 거래 기록을 다시 가져올 수 있습니다. 같은 거래는 중복 저장되지 않도록 거래소 식별자를 기준으로 정리합니다.

## 3. 보관 방식

- 데스크톱 앱에서는 API 정보가 브라우저 저장소가 아니라 운영체제의 보안 저장소에 보관됩니다.
- API Secret은 화면이나 로그에 표시되지 않습니다.
- 연결을 삭제하면 저장된 해당 거래소 자격 증명도 삭제됩니다.
- 프로그램은 API를 통해 주문·출금 요청을 보내지 않습니다.

## 4. 연결이 되지 않을 때

- API 권한이 읽기 전용인지 확인합니다.
- Secret과 Passphrase를 서로 바꾸어 입력하지 않았는지 확인합니다.
- IP 제한을 설정했다면 현재 공인 IP가 허용되어 있는지 확인합니다.
- 선물 기록을 가져오려면 동기화 화면에서 `SWAP`, 현물 기록은 `SPOT`을 선택합니다.
- 기간을 너무 길게 선택하면 거래소 API 제한으로 시간이 걸릴 수 있으므로 짧은 기간부터 확인합니다.

API Key와 Secret은 다른 사람에게 보내거나 화면 캡처에 포함하지 마세요.
