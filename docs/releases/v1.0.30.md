# Trade Journal v1.0.30

Limited-beta prerelease. Official exchange scope: Deepcoin SWAP and Binance.

- Fixed Strategy Discovery's Playbook link opening an unrelated strategy after
  the registered strategy was archived. Explicit strategy links include archived
  strategies and retain their target when a list or detail request fails.
- Windows startup now verifies the actual WebView2 renderer before creating a
  window. An unsupported renderer fails through the existing installation notice
  and launcher cleanup instead of silently continuing with MSHTML.
- Added regression coverage for archived/missing strategy links, list failures,
  renderer selection, initialization errors and server/instance cleanup.

Local verification: full backend and frontend suites, lint, TypeScript and
production build; isolated-sample browser verification of registration,
archiving and reopening the same strategy. Windows distribution is built by the
existing workflow only after the source commit passes CI.

This remains a prerelease: clean Windows/WebView2-missing machine acceptance and
live exchange acceptance are outstanding. Renderer and cleanup tests use mocks
on macOS; they do not certify those Windows GUI scenarios. No exchange sync,
reconstruction or PnL calculations changed. No macOS asset is published by the
existing Windows release workflow.
