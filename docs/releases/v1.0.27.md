# Trade Journal v1.0.27 release candidate

Windows x64 limited-beta candidate. Prepared locally; not yet published or
accepted for distribution. Official exchange support is Deepcoin SWAP and
Binance SWAP with read-only API credentials.

## Changes since v1.0.26

- Explore the app without API keys in an isolated sample workspace containing
  synthetic trades. Sample edits stay separate from your journal; return to your
  own workspace or reset the sample at any time. Live market charts are unavailable
  in the sample.
- Guided Analytics helps you start with a question before configuring advanced
  analysis. Review presents the main findings first, with evidence and sample
  limitations available for inspection.
- Plan and Playbook history is clearer, including the distinction between plans
  recorded before a trade and retrospective notes. Journal and Plan views share
  planning context, and sample journal and plan results are easier to interpret.
- Review findings can lead into an optional Experiment draft, with clearer
  context for defining and measuring an experiment.
- Credential handling better isolates data profiles and preserves legacy
  credentials during automatic migration. Error tracebacks mask registered
  secrets, and database connections close consistently after transactions.
- Windows packaging uses the exact commit that passed CI tests. Documentation
  now reflects the implemented onboarding, credential, analysis, and release
  behavior.

## Candidate limitations and acceptance

Windows code signing is not complete. Do not treat this candidate as signed;
unsigned builds may trigger Microsoft Defender SmartScreen warnings. Follow the
included Windows start guide and use only files supplied through the official
repository. Do not disable Windows protection.

Clean-machine Windows acceptance and final read-only Deepcoin/Binance smoke
tests remain required before this candidate is distributed as an accepted beta.
No macOS release is validated or included in this candidate's scope.

The production-runtime dependency audit remains clean, and the targeted
Vite/Vitest advisory chain is addressed. Unrelated development-only advisories
remain; this is not a claim that all npm vulnerabilities are fixed.

This application and its analysis are not investment advice or a guarantee of
returns. Report installation, sync, credential, data, or crash issues through
[GitHub Issues](https://github.com/alfredcho91-ux/trade-journal-free/issues) or the
app's feedback link. Never include API keys, secrets, or passphrases in reports.
