# Trade Journal v1.0.28 — UI refinement candidate

Windows x64 limited-beta prerelease. This publication preserves the release hold:
clean-machine Windows acceptance and live read-only Deepcoin/Binance smoke tests
remain required before acceptance for broader distribution. Official exchange
support remains Deepcoin SWAP and Binance SWAP with read-only API credentials.

## Changes since v1.0.27

- P0–P4 UI refinement: centralized dark-theme tokens, restrained surfaces,
  consistent controls, a 56px header and desktop/tablet workspace, clearer screen
  hierarchy, and improved handling of long names and financial values.
- Dialog keyboard handling covers initial focus, Tab containment, Escape and
  focus return. A regression in the nested strategy-removal confirmation was
  fixed and covered by integration tests.
- Existing chart surfaces, grid and labels use the design tokens; chart data and
  calculations are unchanged.
- Journal reduces repeated card borders and emphasizes the period summary and
  trade list through alignment, spacing and separators. Detailed analysis remains
  available through the existing expand control.
- README and architecture now describe the implemented UI and its verification
  limits. Application and packaging version declarations are synchronized.

Routing, query/mutation behavior, filtering, persistence, permissions, financial
calculations, formatter semantics and exchange integration are unchanged by the
UI work. No new UI library or mobile navigation was added.

full test results and sample-based visual/keyboard checks. Journal's subsequent
style-only refinement was checked in KO/EN at 768, 1024 and 1440px, including
table scrolling, expanded analysis and Report focus/Escape return.

Actual browser zoom at 200%, clean-machine Windows acceptance, live exchange
sync, external price charts and real credential/persistence acceptance remain
unverified. Synthetic sample checks do not substitute for those checks.

Known follow-ups: reopening a closed report from the same sample URL; some
mixed KO/EN Risk wording. The report can still be reopened from the trade list.

Windows signing is not certified by this release. Unsigned builds may show
SmartScreen warnings. Do not disable Windows protection. No macOS release is
validated or included. Development-only dependency advisories documented for
v1.0.27 remain; this release does not change dependencies or claim to fix them.
